# ECSKC Customisations

The package that deploys the ECSKC site's customisations and keeps track of the extensions we
write ourselves.

## Language

### Our extensions

**Our extension**:
An extension the registry names, of any Joomla extension type or a Community Builder plugin.
Whether it is installed is a fact about one site, not part of what makes it ours.
_Avoid_: Our plugin, YS plugin

**Registry**:
The curated list of our extensions that the package ships, one entry per extension.
_Avoid_: Plugin list, inventory

**Registry entry**:
The minimal record that identifies one of our extensions unambiguously by its manifest, plus the
facts no manifest carries.
_Avoid_: Plugin record

**Community Builder plugin**:
An extension that Community Builder installs and tracks itself, outside Joomla's extension list.
_Avoid_: CB extension

The administrator menu labels the screen that lists our extensions "Plugins", by maintainer
choice. The label stays. The domain term is still **our extension**.
